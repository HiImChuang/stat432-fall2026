SAheart: LDA/QDA prediction analysis

DATA AND PROCEDURE
- Variables: sbp, typea, age: integer; tobacco, ldl, adiposity, obesity,
  alcohol: numeric; famhist: character (categorical); chd (outcome): integer.
- Missing value: no
- Recoding: famhist Absent=1, Present=2; chd factor levels 0,1 (positive=1).
- CV: seed 43207; stratified training 369 (241/128), test 93 (61/32).
  Shared stratified 10-fold CV. Each iteration fits preprocessing/model on
  nine folds and calculates held-out accuracy, error, and a confusion matrix.
  Variance selection and centered/unit-scaled PCA are fitted within each
  training fold; priors use fitting-sample class frequencies. Select lowest
  mean fold error; ties favor fewer dimensions, then LDA.
- Compared models: traditional LDA/QDA with all nine predictors, LDA/QDA
  with five highest raw-variance predictors, and LDA/QDA with 2,4,6 leading
  standardized PCs (ten candidates). No rows removed or values imputed.

SELECTED MODEL AND ESTIMATED PREDICTION ERROR
1. Chosen model: LDA with four standardized principal components.
2. Refitting and application: after locking selection, centered/unit-scaled
   PCA and LDA were refitted on the whole training set (369 observations).
   The four PCs explain 67.6% of training predictor variance. This refitted
   pipeline was applied once to the reserved testing set (93 observations).
3. Testing performance: error = 20/93 = 21.51%; accuracy = 73/93 = 78.49%.
4. Testing confusion counts (negative=0, positive=1), in TN, FP, FN, TP order:
   TN=56, FP=5, FN=15, TP=17.
   Type I (false positive): FP/(TN+FP) = 5/61 = 8.20%.
   Type II (false negative): FN/(FN+TP) = 15/32 = 46.88%.

MAIN FINDINGS AND LIMITATIONS
Four-PC LDA improves mean CV error over ordinary LDA (30.60%) and QDA
(31.43%); its lead over six-PC QDA (28.45%) is small, not proof of superiority.
Raw-variance subsets performed worse and their rankings depend on units.
The selected classifier misses 15/32 positive test cases (46.88%). Class
imbalance, only 93 test observations, CV selection optimism, and Gaussian
assumptions for skewed/binary predictors limit conclusions. This rerun reuses
the previously evaluated split: it is not new independent validation.
Independence is assumed; performance in other populations may differ.
