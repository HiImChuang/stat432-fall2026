Suppose X = (X1, X2)^T follows a bivariate normal distribution with mean 0 and covariance matrix

S1 = [[1, 0.7], [0.7, 1]]

in Condition 1, and

S2 = [[1, 0.35], [0.35, 0.5]]

in Condition 2. The response is generated by Y = X1 + ε, where ε is independent Gaussian noise. In both settings, we fit a linear regression model using only the first principal component (PC1) of X as the predictor. Assume the training and test data are generated from the same distribution, and the principal component is computed from the training data.

How do the training MSE and test MSE compare between the two covariance settings? Why does changing the scale of X2 while keeping X1 fixed affect the fitted model when we use only PC1?
